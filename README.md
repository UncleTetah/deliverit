# DeliverIt 🚚

Connect. Deliver. Trust.

A delivery platform connecting **senders**, **couriers**, and **recipients** with real-time tracking.

## Stack
- **Frontend:** Vanilla HTML/CSS/JS + Leaflet
- **Backend:** Node.js + Express
- **Database:** PostgreSQL 16
- **Auth:** JWT + bcrypt
